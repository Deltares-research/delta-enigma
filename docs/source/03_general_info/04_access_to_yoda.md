# Access to Yoda

## Overview

Research data within the Delta Enigma project is stored in Yoda. To get access to Yoda so you can upload your data to the relevant work package folder, contact the Data & user manager of that work package. They are responsible for granting and managing upload access for their work package.

```{admonition} Requesting Access
:class: note

Reach out to the Data & user manager of the work package you will be uploading data to (via your data steward). Provide your name, affiliation, and a short description of the data you intend to upload.
```
