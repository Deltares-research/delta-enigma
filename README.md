# Delta Enigma Yoda scripts

## setup 

If you haven't set up `uv`, follow instructions on [uv docs](https://docs.astral.sh/uv/reference/cli/#uv)

Create environment with:
```bash
uv sync
```

In VSCode/Cursor select environment created at `./.venv`

Now python scripts run in the proper environment.

Running scripts from the command line:

```bash
uv run <script/location.py>
```
